Projects

Featured Project · Browser Game

2D Bird-Shooter Action Game

A fast-paced 2D shooter that runs in any browser on desktop or mobile. Players pick a character, aim and fire at waves of birds, and survive as the game gets harder.

  • Built the game loop, physics, aiming, and collision detection from scratch in JavaScript on HTML5 Canvas.
  • Designed difficulty that scales with score: faster birds, enraged red birds, and geese to jump or duck under.
  • Added a power-up system (shields, triple ammo, rapid fire, health) and automatic gun upgrades every 1,500 points.
  • Implemented online two-player matches with PeerJS (WebRTC): one player hosts and shares a 5-letter code, and both race to 7,000 points in a shared world.
  • Supported keyboard and mouse plus dual on-screen joysticks for mobile, and saved high scores with localStorage.
